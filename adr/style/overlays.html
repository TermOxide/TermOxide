Domain 6

Overlays and layering

What replaces overflow: visible once it is gone — dropdowns, tooltips and modals have to escape their parent somehow.

D6.1

A Layer portal primitive, not overflow: visible

accepted

A portal lifts a subtree out of the normal tree and paints it into a separate layer with its own root rectangle. Clipping remains absolute within each layer.

Alternatives considered
  • Re-admit overflow: visible for overlay cases only.
Reasoning

Removing visible (D5.7) left dropdowns, tooltips and modals with no way to escape their parent — a hole that had to be filled deliberately rather than by reintroducing the mechanism just rejected.

With portals, no one ever has to reason about whether a given node escapes its ancestor's clip. It either is in this layer or it is not.

D6.2

Ordered layers, not z-index

reserved

Layer ordering is a stable sort key. v1 ships a single overlay layer above the base; the key is designed as (Layer, i32) so finer ordering can be added without redesign.

Alternatives considered
  • Full CSS z-index with stacking contexts.
  • A fixed enum — Base, Overlay, Modal, Tooltip — with no numeric component.
Reasoning

CSS z-index requires stacking contexts, and stacking contexts interacting with opacity, transform and position to trap children are one of the genuinely notorious complexity sinks in the whole specification.

A (Layer, i32) sort key is the safe generalisation: it grows to arbitrary ordering without ever growing into stacking-context semantics. That is what is reserved for later — not CSS z-index itself, which cannot be added on top of this without becoming the thing it replaced.

D6.3

The layout driver is two-pass from day one

accepted

Solve the base layer, collect portal anchors, then solve each overlay layer against its anchor rectangle, then paint layers in order. v1 ships centred modals, which need no anchor.

Alternatives considered
  • Single-pass v1, rewriting the driver when anchored overlays arrive.
Reasoning

An anchored dropdown must know its trigger's resolved rectangle, which does not exist until the base pass finishes. Building the second pass later is a rewrite of the driver rather than an addition to it — the same category of retrofit cost as clip-at-paint or the measure signature.

Consequences

Centred modals work in a single pass, so v1 can ship the capability without ever exercising the second one. The cost is paid once, in structure.
