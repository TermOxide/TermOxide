Domain 7

Colour and capability degradation

One interface for the developer; the framework absorbs the difference between a modern terminal and a 16-colour session over SSH inside tmux.

D7.1

Colours stay symbolic until paint

accepted

A Style holds descriptors — Accent, Error, Base16(4), Rgb(..) — not resolved output. Developers write one colour vocabulary; the framework degrades it.

Alternatives considered
  • Concrete RGB at authoring time, degraded at emit.
  • Per-tier colour APIs the developer selects between.
Reasoning

Concrete RGB at authoring time destroys the information degradation needs: once Accent has become #7C6AE8, nothing downstream knows it was semantically an accent, and it cannot be mapped onto a user's base16 palette or a named flavour. Per-tier APIs push the matrix onto every developer.

Consequences

This is also what makes D1.3 free: a named palette is one more resolution target for the same symbols.

D7.2

Lowering is two steps, and quantization comes last

accepted

symbolic → resolve against palette → Rgb → interpolate in Oklab → quantize to tier → escape sequence.

Alternatives considered
  • Quantize early, then interpolate within the tier's colour space.
  • Interpolate in sRGB rather than a perceptual space.
  • No colour interpolation at all.
Reasoning

A symbol cannot be interpolated, so resolution must precede animation. Quantizing before interpolating means a 200ms fade on a 16-colour terminal steps through whatever the nearest palette entries happen to be — visible garbage rather than a fade. sRGB interpolation produces muddy midpoints; Oklab is perceptually uniform and the midpoints look like midpoints.

Consequences

This ordering is why the animator sits where it does in the pipeline (D9.1).

D7.3

One TerminalProfile holds every capability

accepted

Colour tier, width oracle, mouse support and protocol support live in a single profile object detected at startup. Degradation targets: truecolor, 256, 16, monochrome, plus optional named palettes.

Alternatives considered
  • Separate capability objects per concern.
  • Environment-variable sniffing at each call site.
Reasoning

Colour tier and width measurement are the same kind of thing — a negotiated agreement with the other end of the pty that can change when a session is reattached. Keeping them together means one detection path, one invalidation path, and one generation counter (D8.5).

The environment also changes styling with no human involved: NO_COLOR, TERM tiers, background-colour detection, the user's base16 palette. The profile is where that actor lives.
